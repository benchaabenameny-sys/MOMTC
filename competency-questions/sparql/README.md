# SPARQL queries of the competency questions

One SPARQL 1.1 query per competency question (CQ1.rq to CQ39.rq), written for MOMTC v2.0.0 and the Akira case-study population. The questions are listed in `../competency_questions.csv` and the results obtained in `../sparql_results.csv`.

The queries were executed in Protégé with Snap SPARQL, with the HermiT reasoner synchronised, so that inferred facts are included in the results. The original CQ1 query used during the evaluation is kept in `evaluation/sparql_evaluated/CQ1.rq`.

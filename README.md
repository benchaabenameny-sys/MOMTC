# MOMTC — A Modular Ontology for Multidimensional Cyber Threat Classification

MOMTC is an OWL 2 DL ontology designed to provide a unified semantic representation of cyber threat knowledge. It integrates and links major cybersecurity standards — MITRE ATT&CK, CVE, CWE, and MITRE D3FEND — across interconnected modules covering threat actors, attack techniques, vulnerabilities, weaknesses, attack execution, and defensive countermeasures.

## Repository Contents
- `MOMTC.owl` — the integrated ontology file (OWL 2 DL), containing all modules.

## How to Use
1. Download `MOMTC.owl`.
2. Open it with [Protégé](https://protege.stanford.edu/) (version 5.6 or later recommended).
3. Use the built-in reasoner (e.g., HermiT) to check consistency and run SPARQL queries via the Snap SPARQL plugin.

# Case study: Akira ransomware

Population (ABox) of MOMTC v2.0 for the Akira case study, derived from CISA advisory AA24-109A (18 April 2024, revised 13 November 2025).

- `akira_individuals.csv`: 110 individuals with their class and source
- `akira_object_assertions.csv`: 142 object property assertions
- `akira_data_assertions.csv`: 54 data property assertions

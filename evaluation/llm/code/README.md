# Code and inputs of the LLM-assisted evaluation

Scripts (comments in French) and input files of the LLM-assisted verification reported in Section 6 of the article. The data files, the requirements and the commands to reproduce the reported values are described in `../../README.md`.

No API key is stored in this repository. Recomputing the reported values from the deposited log (`python tables_article.py`) does not require any key.
